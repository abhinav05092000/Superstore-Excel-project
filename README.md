# Superstore-Excel-project
Superstore Excel Data Analysis — Task 5

Project overview

This repository contains my Task 5 Excel Data Analysis project. The goal was to analyze a structured retail dataset using Microsoft Excel formulas, sorting, filtering, Pivot-style analysis and KPI reporting.

Dataset

Records: 9,994

Core fields: 21

Total Sales: $2,297,199.62

Total Profit: $288,738.98

Profit Margin: 12.57%

Orders: 9,994

Units Sold: 44,541

Dataset note: The workbook uses a self-generated Superstore-style dataset created for this internship project. It follows the common Sample Superstore structure but is not a copy of an official source file.

Workbook structure

Dashboard — KPI cards, charts and key findings.

Raw_Data — untouched transaction-level data.

Working_Formulas — derived fields and Excel formulas.

Pivot_Analysis — five Pivot-style business analyses.

SUMIFS vs PivotTable

Use SUMIFS for targeted, formula-driven metrics. Use a PivotTable when you need flexible exploration across multiple dimensions.

Keeping PivotTables live

Use an Excel Table as the source and refresh the PivotTable after new records are added.
